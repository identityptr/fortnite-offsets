## New SDK

The [`sdk/`](sdk/) folder contains the new SDK generated from live Fortnite
reflection on 18 November 2026. It includes 34,772 native types, 191,107
property offsets, and 29,050 function names across 1,479 packages.
Start with [`sdk/SDK.hpp`](sdk/SDK.hpp), or include one package header such as
`Engine.hpp`.

This SDK contains offset and name metadata. It does not claim complete C++ field
layouts or callable function signatures. See [`sdk/README.md`](sdk/README.md)
for details.
